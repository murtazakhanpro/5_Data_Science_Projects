# 5 Data Science Beginner Projects

A portfolio of five completed, beginner-friendly data science projects by **Murtaza Ali Khan**. Explore practical examples of exploratory data analysis (EDA), data visualization, supervised machine learning, regression, classification, and natural language processing (NLP) with Python and Jupyter notebooks.

## Projects

| Project | What you will explore | Main techniques |
| --- | --- | --- |
| [Advertising Sales Prediction](<Advertisement sales Prediction/README.md>) | Estimate product sales from advertising budgets | Exploratory analysis, linear regression, random forest regression, model evaluation |
| [Used Car Price Prediction](<Car Price Prediction/README.md>) | Build and assess baseline models for used-car prices | Data cleaning, feature preprocessing, Ridge regression, random forest |
| [SMS Spam Detection](<Email_Spam_Detection/README.md>) | Classify text messages as spam or ham | Text preprocessing, TF-IDF, Naive Bayes, logistic regression |
| [Iris Flower Classification](<Iris_Flower_ML_Project/README.md>) | Predict iris species from flower measurements | Exploratory analysis, logistic regression, K-nearest neighbours, cross-validation |
| [Unemployment Trends in India](<UnEmplyment Analysis Using Python/README.md>) | Explore regional and monthly unemployment estimates | Data cleaning, time-based analysis, visualization, descriptive statistics |

Each project folder contains its own README with the data, workflow, results, limitations, and instructions for opening the notebook. Where provided, project documentation and source datasets are included alongside the notebook.

## Getting started

1. Clone or download this repository.
2. Open a project folder and read its README for project-specific details.
3. Open its `.ipynb` notebook in Jupyter Notebook, JupyterLab, or VS Code.
4. Install the Python packages required by that notebook, then run the cells from top to bottom.

The Iris project includes a `requirements.txt`. Other notebooks may use common Python data science packages such as pandas, NumPy, Matplotlib, Seaborn, and scikit-learn. Dataset paths and any additional requirements are described in each project README and notebook.
